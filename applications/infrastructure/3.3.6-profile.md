# 3.3.6 Infrastructure profile

Infrastructure is the hosts, the networking in front of them and host
security. Each other application has hosts of its own; no host is shared. What
the applications share, and Infrastructure holds, is the Oracle tenancy and its
budget, the account's Always Free allowance, and one way of building,
networking and running hosts.
The technical profile is `app-profile.toml` at the root of
[its repository](https://github.com/delphside/infrastructure/blob/main/app-profile.toml).
