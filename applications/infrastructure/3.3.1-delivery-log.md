# 3.3.1 Delivery log

This application's delivery log: one row per delivery, oldest first, for
somebody asking **which planned pieces of work reached their users, when, and
did they work.** It is a programme record
([1.3](../../docs/1.3-workstreams.md#programme-and-application)). What gets a
row, how a delivery is identified and when the row is written are
[1.2 §2.14](../../docs/1.2-change-lifecycle.md#the-delivery-log-row-is-part-of-the-delivery);
the columns are [the template](../../docs/templates/delivery-log.md). Change
history is derived from git, not from here.

**It starts with the shared infrastructure project,
delphside/tile-lite-elite#489.** Each delivery is identified by its date and the
day's sequence, `YYYY.MM.DD-n`, because a host change builds no version, so a
semver's parts would measure nothing.
Host maintenance before this log is in
[Tile Lite Elite's](../tile-lite-elite/3.1.1-delivery-log.md).
