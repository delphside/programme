# 3.2.6 Dark Portal profile

An analysis tool for the World of Warcraft auction house, in design. This is
what the programme's processes need to know about it; the form is
[the template](../../docs/templates/application-profile.md). The technical
profile is `app-profile.toml` at the root of
[its repository](https://github.com/delphside/dark-portal/blob/main/app-profile.toml).
