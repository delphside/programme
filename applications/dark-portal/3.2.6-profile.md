# 3.2.6 Dark Portal profile

An analysis tool for the World of Warcraft auction house, in design. The form is
[the template](../../docs/templates/application-profile.md). The technical
profile is `app-profile.toml` at the root of
[its repository](https://github.com/delphside/dark-portal/blob/main/app-profile.toml).

## Environments

In the order a change reaches them. The other environments it needs, and where
they run, are decided in delphside/dark-portal#11 *MAIN PROJECT: Development,
release and environments*. Where a URL is not fixed, the technical profile's
`environments` key gives the variable that sets it.

| Environment | Purpose | URL |
| --- | --- | --- |
| production | what the owner uses, and where the collector will gather the auction data | not fixed: private and reached over SSH ([6.3.4](https://github.com/delphside/infrastructure/blob/main/docs/6.3.4-hosts.md#reaching-an-application)), set by `PROD_URL` |

## Routes

The routes its deliveries take, from
[1.2 §2.15](../../docs/1.2-change-lifecycle.md#route); the artefacts under each
are in [3.2.2](3.2.2-artefacts.md#artefacts-by-route).

| Route | When a change on it reaches its users |
| --- | --- |
| Production Release | when the release is deployed to production |
| Application Tooling | when its branch merges and is pushed to `origin/main` |
| Docs and Programme Tooling | when it is pushed to `origin/main` |
| Other | when somebody applies it |
