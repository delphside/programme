# 3.2.2 Dark Portal artefacts

Dark Portal's artefact register, in two parts: its artefacts by route, and
everything under change control that leaves no trace in git. For the second
part this file is the only record, so each entry carries enough to recreate it.

## Artefacts by route

The rule is [1.2 §2.15](../../docs/1.2-change-lifecycle.md#route); this is its
answer here.

| route | Dark Portal's artefacts |
| --- | --- |
| Production Release | none yet: the collector's image (the collector fetches the auction house data each hour), and whatever its deliveries install on the host |
| Application Tooling | none yet: the scripts that build, deploy, operate and measure it |
| Docs and Programme Tooling | the `5.x` documents changed on their own, and anything else in `delphside/dark-portal` |
| Other | the Oracle Cloud (OCI) console and GitHub settings. The host's maintenance (its base packages, the container runtime, reboots) is [Infrastructure's](../infrastructure/README.md) delivery, numbered by date ([1.2 §2.15](../../docs/1.2-change-lifecycle.md#host-maintenance-is-the-infrastructure-applications)), and marked `Other, host maintenance` below |

## The host

The VM was verified by the owner, 2026-10-21, as built from the build runbook of
delphside/dark-portal#6, the host's work package.

- The host is Infrastructure's; it is recorded here until Infrastructure has an
  artefact register of its own.
- It is pre-production while Dark Portal is built: one user, reached by SSH.

| artefact | route | what it is | why it is not in the repository |
| --- | --- | --- | --- |
| `OCI compute dark-portal` | Other | the Dark Portal VM, `uk-cardiff-1`, `VM.Standard.A1.Flex` with 1 OCPU and 6 GB, burstable off, inside the Always Free allowance. Ubuntu 26.04 LTS Minimal, `aarch64`, the default 47 GB boot volume | a console resource |
| `dark-portal:` Docker Engine and Compose plugin | Other, host maintenance | from Docker's apt repository; user `ubuntu` is in group `docker` | installed by hand |
| `dark-portal:` `jq` | Other, host maintenance | a JSON processor for the command line | installed by hand |
| `dark-portal:` `unattended-upgrades` | Other, host maintenance | security updates applied automatically | installed by hand |
| `OCI` budget | Other | £1 a month, alert at 100%, created 2026-10-21. Account-wide: the account is Pay As You Go, so use beyond Always Free is billed rather than refused | a console resource |

The host's address is held in the owner's SSH configuration as `dark-portal`
and is not recorded here: the repository is public.
