# 3.2.2 Dark Portal artefacts

Dark Portal's artefact register, in two parts: its artefacts by route, and
everything under change control that leaves no trace in git. For the second
part this file is the only record, so each entry carries enough to recreate it.
The code does not exist yet, so the register so far is the host.

## Artefacts by route

The rule is [1.2 §2.15](../../docs/1.2-change-lifecycle.md#route); this is its
answer here.

| route | Dark Portal's artefacts |
| --- | --- |
| Production Release | none yet: the collector's image, and whatever the collector's deliveries install on the host |
| Application Tooling and Docs | none yet: the scripts that build, deploy, operate and measure it, and its `5.x` documents |
| Programme Tooling and Docs | anything else in `delphside/dark-portal` |
| Other | the OCI console, GitHub settings, and the host's base packages, installed by hand while the host is Infrastructure's |

## The host

The host is [Infrastructure's](../infrastructure/README.md); it is recorded here
until Infrastructure has an artefact register of its own. It is pre-production
while Dark Portal is built: one user, reached by SSH. Built and checked by the
owner, 2026-10-21, from a build runbook that becomes the host delivery's change
document once Dark Portal's project is raised.

| artefact | route | what it is | why it is not in the repository |
| --- | --- | --- | --- |
| `OCI compute dark-portal` | Other | the Dark Portal VM, `uk-cardiff-1`, `VM.Standard.A1.Flex` with 1 OCPU and 6 GB, burstable off, inside the Always Free allowance. Ubuntu 26.04 LTS Minimal, `aarch64`, default boot volume | a console resource |
| `dark-portal:` Docker Engine and Compose plugin | Other | from Docker's apt repository; user `ubuntu` is in group `docker` | installed by hand |
| `dark-portal:` `jq`, `unattended-upgrades` | Other | security updates applied automatically | installed by hand |

The host's address is held in the owner's SSH configuration as `dark-portal`
and is not recorded here: the repository is public.

## Not yet recorded

None of these has an issue yet; Dark Portal's project, once raised, owns them.

- **the network**: the VCN, subnet and security list the instance joined.
- **the budget alert**: £1 a month, alert at 100%, because the account is Pay
  As You Go and use beyond Always Free is billed rather than refused; recorded
  once the owner confirms it is created.
- **the boot volume's size**: the default was taken; its size goes here once
  read.
- **the collector, its credentials and its data**: recorded when the collector
  is deployed.
- **backups, and keeping collection running through reboots and patching**:
  designed with the collector.
