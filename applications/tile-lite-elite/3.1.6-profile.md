# 3.1.6 Tile Lite Elite profile

A multiplayer word-tile game, in production. What the programme's processes
need to know about it is below; the form is
[the template](../../docs/templates/application-profile.md). The technical
profile, how a version is read, what ships and the commands, is
`app-profile.toml` at the root of
[its repository](https://github.com/delphside/tile-lite-elite/blob/main/app-profile.toml).

## Environments

In the order a change reaches them. Where a URL is not fixed, the technical
profile's `environments` key gives a default, or the script to source and the
variable it sets.

| environment | purpose | URL |
| --- | --- | --- |
| preview | user functional testing | not fixed: a developer's own machine |
| rehearsal | technical testing, and the release gate | not fixed: the rehearsal host, which the rehearsal scripts set |
| production | what users have | `https://tileliteelite.com` |

## Routes

The routes its deliveries take, from
[1.2 §2.15](../../docs/1.2-change-lifecycle.md#route); the artefacts under each
are in [3.1.2](3.1.2-artefacts.md#artefacts-by-route).

| route | when a change on it reaches its users |
| --- | --- |
| Production Release | when the release is deployed to production |
| Application Tooling | when its branch merges and is pushed to `origin/main` |
| Docs and Programme Tooling | when it is pushed to `origin/main` |
| Other | when somebody applies it |
