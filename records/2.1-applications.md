# 2.1 Applications

The applications the programme manages. The index *n* places an application's
records at `3.n.x` and its documents at `(3+n).x`
([1.5](../docs/1.5-writing-documents.md#each-range-covers-one-scope)).

| Index | Code | Application | Repository | Purpose | Folder in this repository | Its own documents |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | TLE | Tile Lite Elite | `delphside/tile-lite-elite` | a multiplayer word-tile game; in production | [`applications/tile-lite-elite/`](../applications/tile-lite-elite/README.md) | 4.x |
| 2 | DP | Dark Portal | `delphside/dark-portal` | an analysis tool for the World of Warcraft auction house; in design | [`applications/dark-portal/`](../applications/dark-portal/README.md) | 5.x |
| 3 | INF | Infrastructure | `delphside/infrastructure` | what the applications share: the hosts, networking and security; in production | [`applications/infrastructure/`](../applications/infrastructure/README.md) | 6.x |

The owner decides to add an application and Claude records it here. It takes
the next index, as
[1.5](../docs/1.5-writing-documents.md#each-range-covers-one-scope) numbers it.
[Each application's profile](#what-each-applications-folder-holds), `3.n.6`,
holds the detail of what it is.

An application's code is the *owner* part of a report's name,
`<OWNER>_<CODE>_<period>.md` (`TLE_CP_2026_09.md`), as
[1.2 *Which document goes where*](../docs/1.2-change-lifecycle.md#which-document-goes-where)
sets out.

## What each application's folder holds

The same record, under the same suffix, in every application:

| Record | File or folder | Template |
| --- | --- | --- |
| 3.n.1 delivery log | `3.n.1-delivery-log.md` | [delivery-log](../docs/templates/delivery-log.md) |
| 3.n.2 artefact register | `3.n.2-artefacts.md` | [artefact-register](../docs/templates/artefact-register.md) |
| 3.n.3 capacity plans | `3.n.3-capacity-plan/` | [capacity-plan](../docs/templates/capacity-plan.md) |
| 3.n.4 workstreams | `3.n.4-workstreams.md` | [workstream-register](../docs/templates/workstream-register.md) |
| 3.n.5 role holders | `3.n.5-roles.md` | [role-assignment](../docs/templates/role-assignment.md) |
| 3.n.6 application profile | `3.n.6-profile.md` | [application-profile](../docs/templates/application-profile.md) |
| 3.n.7 change documents | `3.n.7-changes/` | the folder's README (Tile Lite Elite's: [3.1.7-changes/README.md](../applications/tile-lite-elite/3.1.7-changes/README.md)) |

A record not yet written has no file.
