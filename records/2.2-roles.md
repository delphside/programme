# 2.2 Programme role holders

Who holds the roles that belong to the programme as a whole, rather than to one
application. The roles are defined in [1.7](../docs/1.7-roles-and-responsibilities.md);
each application's own holders are its `3.n.5`, listed in
[2.1](2.1-applications.md). The form is
[the template](../docs/templates/role-assignment.md).

| role | held by |
| --- | --- |
| owner | Stephen, for the programme and for every application in it |
| design authority | for Process Definition and Programme Tooling, the programme authority below; for each application's workstreams, the owner threads in its `3.n.5` |
| technical lead | a thread per project or work package, for its life |
| demand manager | the coordinator; each area's owner triages its own area |
| test manager, librarian | the programme authority |
| security | policy: the programme authority; an application's controls: the holder in its `3.n.5` |

| owner thread | design authority for | kind | runs |
| --- | --- | --- | --- |
| programme authority | Process Definition, Programme Tooling | permanent | cloud |
| coordinator | none: the demand manager | permanent | cloud |
